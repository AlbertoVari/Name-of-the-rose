# Release notes

## v0.1.0 — The first reading

- Source-grounded transaction/GL/CTR ontology with 12 objects, 98 properties,
  16 links, 8 descriptive actions and 22 business rules.
- Hash-locked lexical extraction, evidence validation, deterministic JSON-LD and
  mapping exports, plus offline annotation search.
- Umberto, Peter, Satya, Boris and Eric Copilot profiles, reusable skill, prompts,
  bounded orchestration protocol, validated ledger schema and gate checker.
- Italian institutional crosswalk with ten primary references and explicit gaps.
- Regression tests, GitHub Actions workflow, worked demo, backlog and MIT license.

The POC exposes missing integration rather than rewriting COBOL. It does not
execute banking actions, submit reports, validate proprietary CBI profiles,
certify compliance or claim a live Copilot run. Original COBOL is not bundled.
Publication status is recorded in docs/acceptance.md; this file is release-note
content, not evidence that a GitHub release exists.
